# Fondos Oficiales de Meraki Spa & Beauty

Esta carpeta contiene los fondos oficiales utilizados en el Hero / Sección Principal de la web de Meraki:

- `fondo-desktop.webp`: Versión para pantallas de escritorio y tablets en orientación horizontal (Desktop, mínimo 1920x1080 o similar en formato WebP / JPG / PNG).
- `fondo-mobile.webp`: Versión para teléfonos móviles y pantallas verticales (Mobile, proporción vertical 9:16 o 1080x1920 en formato WebP / JPG / PNG).

Los archivos se sirven de manera responsive utilizando `<picture>` con media queries `(min-width: 768px)` y `(max-width: 767px)`.
